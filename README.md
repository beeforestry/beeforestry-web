# BeeForestry website

Sitio público de BeeForestry (Puerto Rico): rescate y remoción de abejas sin exterminio, preparación de sistemas agroforestales, y colmenas y cajas de abejas.

- Sitio: https://beeforestry.github.io/beeforestry-web/
- Contacto: 787-598-3543 · Beeforestry@gmail.com · Instagram @beeforestry

## Notas técnicas

- Los formularios de cotización y colaboración se envían por FormSubmit (AJAX) a Beeforestry@gmail.com (`app.v9.js`). FormSubmit requiere confirmar una sola vez el correo de activación que envía la primera vez; hasta entonces el sitio muestra un mensaje de error y ofrece enviar la solicitud por WhatsApp.
- Las fotos no se adjuntan en el formulario: se le pide al cliente enviarlas por WhatsApp o Instagram.
- `sitemap.xml` lista la página principal.
